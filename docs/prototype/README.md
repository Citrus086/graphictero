# Graphictero 原型 v4.6

Graphictero 是一个独立的 Mac 应用（D90、D91），这里是它的可点击网页原型。设计依据是 Notion MVP 文档里的决策 D1–D91（各条在原型里的位置见「决策覆盖 D1–D91」）；v4.5 按开发 2 的复核意见和 D83–D89 修正（见文末「v4.5 修改」）。Notion 文档只读，原型没有改动它。

界面里的论文内容、数值、年份（YYYY）和 DOI 都是**示例**，不是论文的真实结论。

## 运行

```bash
cd paper-graph-prototype && python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/#/02
```

可以用两种方式指定页面：`#/0N` 或 `?screen=0N`。加上 `&theme=dark` 切换深色主题。

### 对话抽屉（D30）

画布、详情页、关系页和阅读器都用同一个对话抽屉。

- **顶部**：会话下拉（按时间排序，可新建、重命名、删除），下面一行显示对话对象（整张图谱 / 论文 / 关系）。
- **宽度**：左边缘可以拖动，宽度在 300–560 px 之间；可以收起。
- **对话记录**里会出现这些内容：
  - 灰色、可折叠的读取记录，例如「读了 HALT §4」
  - 图谱改动摘要，带「定位」和「⌘Z 撤销」
  - 候选论文卡片
  - 论文原图块，点击跳到 PDF 对应页
  - 小图表，附数据来源说明
  - Agent 运行中时显示「停止」按钮
- **输入框**上方显示上下文 chip，来源可以是拖进来的论文、@ 提到的论文，或 PDF 里选中的文字。

## v4 相对 v3 的变化

- 去掉了 AI 建议层：不再有虚线建议边、接受 / 拒绝按钮和「N 条建议」。
- 新增候选论文节点、对话抽屉、PDF 阅读器（07）和导出对话框（08）。
- 详情页改成自由排版的解读全文，不再用固定字段卡片。
- 接 Zotero 的方式改为单向导入；模型改为 DeepSeek deepseek-flash。
- 画布会缩放以适应窗口；「整理」使用 dagre 分层布局，并分散各边的连接点。

## 检查

`/workspace/pwtool/shots.js` 会给 01–08 和各个状态截图，存到 `shots/`，同时检查以下几项：

- 边与边是否交叉
- 边是否穿过节点
- 节点是否重叠
- 节点是否超出画布

检查覆盖了这些情况：初始状态、「整理」之后、确认候选之后、忽略候选之后、收起对话之后。所有情况下结果都是 0。
